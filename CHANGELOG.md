- Evidence collection framework with control-family mapping
- FIPS 140-3 CMVP readiness module
- Multi-framework mapping: SOC 2, CMMC v2, ISO 27001, PCI DSS 4.0.1, NIST CSF 2.0, FedRAMP
- Policy and procedure template library
- Standalone HTML audit dashboard
- NIST SP 800-53 Rev 5 control family coverage
- Offline / air-gap compatible architecture
