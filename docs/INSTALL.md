# ForgeGRC — Installation Guide

This guide covers installation, initial configuration, and first-run setup for ForgeGRC.

## Requirements

- Python 3.8+
- Linux, macOS, or Windows (WSL2 recommended for Windows)
- Optional: OpenSCAP, Anchore CLI for live scanning integration

## Installation

### Option 1: Download Release ZIP (Recommended)

1. Download the latest release from: https://github.com/IAwiz87/ForgeGRC/releases/latest
2. Extract the ZIP to your working directory
3. Follow the configuration steps below

### Option 2: Clone from GitHub

```bash
git clone https://github.com/IAwiz87/ForgeGRC.git
cd ForgeGRC
```
